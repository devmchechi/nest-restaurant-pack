# Guest Review Responder

Analyzes diner feedback from Google, Yelp, and OpenTable, extracting operational sentiment trends and drafting personalized, professional public responses.

## Working Folder Structure

- Exported Reviews: `./reviews/`
- Response Guidelines: `./guidelines/`
- Draft Responses: `./responses/`

## Example Prompts

- "Analyze guest reviews from this weekend in ./reviews/google_reviews.csv and categorize complaints."
- "Draft a gracious, de-escalating response to this 1-star review complaining about slow service."
- "What food items are receiving the most compliments in recent reviews?"
