# Inventory Waste Tracker

Analyzes daily kitchen waste logs, inventory count sheets, and customer covers to forecast dynamic ingredient par levels and minimize food spoilage.

## Working Folder Structure

- Waste Logs & Counts: `./inventory/`
- Supplier Catalogs: `./suppliers/`
- Order Guides: `./orders/`

## Example Prompts

- "Analyze the kitchen waste logs in ./inventory/waste_week42.csv and highlight top losses."
- "Calculate supplier order quantities for tomorrow based on current on-hand counts."
- "What prep adjustments should we make to stop throwing away prepped sauces on Mondays?"
